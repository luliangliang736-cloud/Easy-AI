# 创意工具箱 / 材质库迁移说明

> 2026-07 从 Vibstar（VibstarDesign）迁移。本项目与 Vibstar 同源（Vibstar 的创作台最初就是从本项目拆出去的），因此画布、生成管线、云同步的结构高度一致，迁移以"拷贝 + 少量适配"为主。

## 功能概览

画布底部工具栏右侧新增一个独立胶囊「创意工具箱」，包含：

- **风格迁移（一键换材质）**：选中画布上的一张图片后，打开材质库面板点选材质球，即基于该图发起一次改图（材质替换）。可叠加配色方案。
- **创意工具**：占位入口，弹出"更多创意玩法即将上线"。

材质库面板（`MaterialPanel.jsx`）的能力：

- 官方材质分类浏览 + 收藏（星标）
- 配色方案库 + DIY 自定义配色（取色器）
- 组合探索：勾选多个材质 + 配色，一次生成；组合可存为命名预设
- DIY 材质：用户自定义材质名 + 提示词，可用 AI 生成"材质球缩略图"（走 `/api/generate`，模型 `gemini-3.1-flash-lite-image`，生成后异步转存 `/api/cloud-assets/upload` 换永久链接）
- 面板可拖拽、可缩放、可最小化成胶囊
- 选中图片时点击材质球直接生成；未选中时给 toast 提示

## 迁移的文件

| 文件 | 说明 | 适配点 |
|------|------|--------|
| `src/lib/materials.js` | 材质数据 / 配色 / 提示词拼装 | 原样拷贝（纯数据 + 纯函数） |
| `src/components/MaterialPanel.jsx` | 材质库浮窗 | localStorage key 前缀 `vibstar-` → `lovart-` |
| `public/images/materials/*.png` | 官方材质球图（34 张） | 原样拷贝 |

## 目标项目内的接线改动

1. **`src/components/Toolbar.jsx`**
   - 原单胶囊拆为外层 wrapper + 胶囊 1（原工具）+ 胶囊 2（创意工具箱）。
   - 新 props：`onToggleMaterialPicker` / `isMaterialPickerOpen` / `onToggleCreativeTools` / `isCreativeToolsOpen`。
   - 首次引导提示（`lovart-creative-toolbox-hint-dismissed`）+ 呼吸光效 `.material-swap-attention`。

2. **`src/components/Canvas.jsx`**
   - 引入并条件渲染 `<MaterialPanel>`（`isMaterialPickerOpen` 时，挂在 `data-toolbar` 容器里，面板自身按 offsetParent＝画布相对容器定位）。
   - 新 props：`onApplyMaterial` / `onApplyCombo`。
   - `handlePickMaterial` / `handlePickCombo`：校验"已选中一张图片、非视频/SVG"后转发给上层。
   - `handleWheel` 开头新增豁免：事件目标在 `[data-material-picker-root]` 或 `[data-canvas-wheel-ignore]` 内时不缩放画布（把滚轮留给面板内部滚动）。
   - 创意工具浮层的点击外部自动关闭。

3. **`src/app/canvas/page.js`**
   - 引入 `buildMaterialEditPrompt` / `buildComboEditPrompt`。
   - 新增 `handleApplyMaterial` / `handleApplyCombo`：探测原图尺寸（`detectRefImageMeta`）→ `handleGenerate({ text, displayLabel, refImages: [原图], image_size: "auto", num: 1, preserveComposer, hideConversationMessages, disableAgentDefaults, composerMode: "manual" })`。
   - `handleGenerate` 内 `displayText` 支持 `payload.displayLabel`：聊天记录/画布提示词标签展示"材质：xxx"短标签，而不是完整材质提示词。
   - `<Canvas>` 传入 `onApplyMaterial` / `onApplyCombo`。
   - `CANVAS_CLOUD_STATE_KEYS` 加入 4 个材质 key。

4. **云同步（跨设备保留收藏 / DIY 数据）**
   - `src/lib/server/cloudStateStore.js` 的 `CLOUD_STATE_KEYS` 加入 4 个 key。
   - `src/lib/useCloudLocalStorageSync.js` 加入 `EMPTY_LIST_PROTECTED_KEYS`：这 4 个 key 的**空数组永不上传**，防止新设备首次打开面板时用空列表覆盖云端已有收藏（Vibstar 曾踩过这个坑）。
   - 面板监听 `CLOUD_STATE_RESTORED_EVENT`，云端数据落地后自动刷新面板内状态。

5. **`src/app/globals.css`**（文件末尾"创意工具箱 / 材质库"段）
   - `.material-swap-attention` 呼吸光效（用本项目品牌绿 `rgba(63,202,88,…)`）。
   - 深色模式下 `[data-material-picker-root]` 内层级 token 提亮一档。
   - `.palette-color-input` 原生取色器圆角化。

## localStorage / 云同步 key 一览

| key | 内容 |
|-----|------|
| `lovart-material-favorites` | 收藏的材质 id 数组 |
| `lovart-custom-palettes` | DIY 配色方案数组 |
| `lovart-combo-presets` | 组合预设数组（材质 id + 配色快照） |
| `lovart-custom-materials` | DIY 材质数组（name/prompt/color/thumb） |
| `lovart-creative-toolbox-hint-dismissed` | 新手引导已点掉（仅本地，不同步） |

> 增删同步 key 时，`cloudStateStore.js`、`useCloudLocalStorageSync.js`、`canvas/page.js` 三处必须同步修改。

## 依赖的既有能力（未改动）

- `/api/generate`：透传 `model`，DIY 材质球缩略图用 `gemini-3.1-flash-lite-image`；响应形如 `{ data: { urls } }`。
- `/api/cloud-assets/upload`：接受 `{ sourceUrl, filename, scope }`，用于把临时生成图转存为永久链接。
- `useToast` / `useCanvasT` / 主题 token（`bg-bg-*` / `text-text-*` / `accent`）。

## 与 Vibstar 版本的差异

- localStorage / 云同步 key 前缀：`vibstar-` → `lovart-`（跟随本项目既有命名）。
- 呼吸光效颜色：Vibstar 亮绿 `#AEFF61` → 本项目品牌绿 `#3FCA58`。
- **未迁移**：选中图片时悬浮卡上的"快捷换材质条"（Vibstar 里嵌在图片操作浮层里的一排推荐材质球）。两个项目的图片浮层结构差异较大，为降低风险暂未搬运；如需要可参考 Vibstar `Canvas.jsx` 里 `QUICK_SWAP_MATERIALS` 相关代码补上。
- 工具栏按钮激活态文字颜色跟随本项目惯例用白色（Vibstar 为黑色，因其 accent 是亮绿）。
